# H23 Works Website Manager

This version adds structured editing for hero text, contact details, social links, homepage statistics, services, projects, testimonials and FAQs. Projects support image uploads through Decap CMS.

The CMS is not authenticated yet. Do not use /admin/ until GitHub OAuth is configured in Netlify.

The editor is intentionally structured rather than a free-form page builder, so the cinematic design cannot be accidentally broken. More section types can be added later.
