# H23 Works — Version 7.9 Preview

## Run locally
1. Extract this ZIP to a folder such as `Desktop\H23-V7.8`.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Review desktop and mobile layouts, hover states, portfolio cards, contact links, Privacy Policy and Terms & Conditions.

## Included in this preview
- Custom desktop pointer with hover expansion and blue glow
- Responsive navigation and service-card hover effects
- Six AI-generated portfolio concept visuals
- AI-generated image-led service cards for Chat Support, Voice Support, Website Design/Development/Maintenance, and Business Automation
- Compact client testimonial
- Highlighted phone, email, Instagram and legal links
- Email contact links open Gmail compose in a new browser tab
- Enquiry form configured to post to the existing H23 Google Apps Script endpoint; fallback opens a prefilled Gmail draft
- Privacy Policy and Terms & Conditions draft pages

## Important scope note
Version 7.9 is a **standalone visual preview**, created because the exact V7.7 source project was not attached to this chat and could not be retrieved from the production repository here. It is not a byte-for-byte modification of your production project and does not include the Decap CMS setup. Do not copy it over your production folder or deploy it to Netlify as a replacement yet. After you inspect it, provide the actual production project ZIP so the approved design can be merged into the production code while preserving the CMS and all existing integrations.
