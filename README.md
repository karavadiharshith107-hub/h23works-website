# H23 Works

Cinematic H23 Works website with a browser-based content manager powered by Decap CMS, Netlify Identity and Git Gateway.

Live site: https://h23works.netlify.app/

## Editable from `/admin/`
Home, Services, Our Work, About, Testimonials, FAQ, Contact & Socials, and Site Settings.

- Website Maintenance is a separate service. Chat Support and Voice Support remain separate services.


## Legal pages
- `privacy.html` contains the current website privacy-policy draft.
- `terms.html` contains the current website terms draft.
- Review both with an Indian privacy/legal professional before relying on them as definitive legal documents.
